## 当前评测口径

- JD 技能抽取 F1：93.88%，5 条人工金标样本。
- 简历技能抽取 F1：95.65%，4 条人工金标样本。
- 人岗匹配 Top-1：100%，5 条回归样本；预测由当前数据库岗位图谱和统一证据评分实时生成，不再使用手写预测。
- 自动化测试覆盖率：每次运行 `python -m app.evaluation.run_coverage` 后更新，页面读取报告文件，不写死数值。

这些指标用于回归验证。由于金标总量仍小，不能表述为大规模模型准确率。

## 比赛前仍需完成

1. 从企业官网、公开招聘数据集或经授权渠道导入不少于 100 条真实 JD，并保留逐条原始链接、发布机构和发布日期。
2. 组织人工标注，形成不少于 100 条 JD 的技能/职责金标集；将训练调参集和最终测试集分开。
3. 用户提供新的 DeepSeek API 密钥后，在本机环境变量中配置，分别实测 JD、简历、匹配解释、学习路径、面试和新兴岗位分析；密钥不得写入仓库。
4. 扩大人岗匹配金标集，覆盖相近岗位、跨领域岗位和低信息简历，并补充 Top-3、MRR 等指标。
5. 最后阶段再统一优化三端大屏和个人端视觉，避免视觉修改掩盖数据与功能缺口。
