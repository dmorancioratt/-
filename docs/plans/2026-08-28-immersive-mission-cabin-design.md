# 沉浸任务舱设计

## 目标

点击 3D 驾驶舱中的任一模型后，页面延续当前空间氛围，进入对应的沉浸任务舱。详情层必须与 3D 场景保持视觉连续，并在首屏回答三个问题：当前状态是什么、下一步做什么、完成后获得什么。

## 体验结构

任务舱覆盖主视口，保留经过压暗、虚化和位移处理的 3D 驾驶舱作为背景。入场分为三步：模型聚焦、界面扫描、内容展开。返回时反向播放，恢复原来的摄像机和场景交互。

每个任务舱共用以下骨架：

1. 顶部导航：模块编号、英文代号、中文名称、状态和返回按钮。
2. 左侧任务叙事：核心结论、当前阶段、关键指标和主行动。
3. 中央主视觉：路径、图谱、档案、资源、AI 助手、日历或成就的专属表达。
4. 右侧行动轨：下一步任务、预计收益、完成条件和辅助操作。
5. 底部状态带：数据更新时间、AI 建议依据和当前任务进度。

## 七个模块

- 能力图谱：以技能星图和缺口轨道为中心，突出优势、短板和岗位匹配提升空间。
- 学习路径：以职业航线为中心，显示已完成节点、当前任务和目标岗位。
- 成长档案：以数字身份档案为中心，展示能力等级、项目证据和成长趋势。
- 资源库：以精选资源舱为中心，按“阅读、实战、交付”组织资源，并支持加入计划。
- AI 助手：以 AI 决策核心为中心，解释推荐原因，给出一条明确的下一步行动。
- 计划日历：以本周任务编排为中心，显示优先级、时间预算和完成状态。
- 成就奖杯柜：以成长里程碑为中心，展示已解锁成就、下一枚徽章和能力增益。

## 视觉系统

整体采用深海军蓝和低饱和金属色，延续现有舱体质感。青色作为系统状态色；各模块只增加一种识别色。界面使用细线框、坐标刻度、扫描光和轻量颗粒，不堆叠常规玻璃卡片。

任务舱使用统一排版节奏：短标题、明确数字、少量说明。动画集中在入场、主视觉和主行动反馈，避免持续闪烁。用户开启“减少动态效果”后，转场改为淡入淡出。

## 组件与状态

在 `GrowthCockpit.vue` 内保留现有数据和业务入口，将详情层拆为配置驱动的任务舱外壳与七个模块内容区。`GrowthCockpitScene.vue` 继续负责模型拾取和镜头聚焦，并向父组件发送模块标识。

父组件维护 `activePanel`、入场阶段和返回状态。模块配置提供编号、颜色、状态、核心指标、主行动和辅助行动。失败或缺失数据时，任务舱显示可解释的占位状态，不阻断返回驾驶舱。

## 响应式与可访问性

桌面端采用三列沉浸布局。窄屏改为单列内容流，3D 场景退为顶部氛围背景。所有交互提供键盘焦点和文字标签；颜色不单独承担状态含义；动画尊重 `prefers-reduced-motion`。

## 验收

1. 七个模型都能打开对应任务舱并正确返回。
2. 1366×768 首屏可看到模块名称、核心结论、主视觉和主行动。
3. 任务舱与 3D 背景保持连续，无普通后台面板的割裂感。
4. `npm run build` 通过。
5. Playwright 验证至少七个入口、返回流程、桌面截图和窄屏布局。
