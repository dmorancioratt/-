# 求职者概览整合设计

## 目标

将求职者最常用的成长驾驶舱能力整合进 `/overview`，用一个从上到下的工作台减少页面跳转；职责不同的岗位、能力图谱和后台管理页面继续保持独立。

## 页面结构

1. 固定顶部导航：保留产品导航和身份入口，并为概览各段提供锚点式入口。
2. 首屏职业进化区：左侧匹配度与能力摘要，中部职业平台视频与成长路线叠层，右侧当前焦点能力和推荐动作。
3. 成长进度条：集中展示档案、简历、岗位匹配和面试四项状态。
4. 本周行动与资料证据：聚合原驾驶舱的下一步任务、个人资料与简历证据。
5. 深度操作保留在独立页：岗位管理、能力图谱、完整匹配分析、简历编辑和模拟面试等通过“查看详情”进入，避免总览变成难以操作的大表单。

## 数据与异常

概览继续使用已有的概览、个人资料、简历、匹配记录、面试记录和市场快照接口。接口为空时显示面向行动的引导；视频播放不可用时以同一视觉容器中的动态渐变背景降级。

## 验证

运行前端 TypeScript 与生产构建，检查视频资源已纳入静态目录，并通过浏览器检查桌面与窄屏布局。
