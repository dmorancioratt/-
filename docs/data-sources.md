## 数据边界

- 公开市场数据与候选人隐私数据严格分层。候选人、简历、匹配和面试记录只能来自系统用户授权输入，不会通过网络虚构或抓取个人信息。
- O*NET 数据按 CC BY 4.0 使用并保留来源与修改声明。本系统只把英文职业技能映射到中文应用场景，映射结果不代表美国劳工部官方中文翻译或背书。
- 招聘网站岗位详情通常受服务条款、版权和反爬规则约束，因此没有把未经许可的职位爬虫伪装成“实时真实数据”。后续如获得招聘平台正式 API 授权，可作为新的来源接入。

## 三端联通

- 管理端：`POST /api/data-sources/sync` 执行联网更新；`GET /api/data-sources/status` 查看同步结果。
- 企业端：`GET /api/market/snapshot` 读取权威市场规模、趋势、热门技能和新职业。
- 个人端：复用同一市场快照，并与用户自己的画像、简历、匹配和面试历史组合展示。
- 公共检索：`GET /api/market/catalog` 按职业、技能、软件技能、核心技能或证书检索本地索引。

## 统一职业能力目录

- 当前目录版本为 `2026.08-authority-v1`。岗位管理、能力图谱、新岗位发现、匹配分析和学习路径共用同一个版本。
- 人社部公示的 4 个新职业与 WEF 的 5 个趋势岗位已进入正式岗位实体库，不再只作为页面展示数据。
- 每个岗位统一返回必备能力、加分能力、建议证书、O*NET 对应职业代码以及原始来源。
- 证书与岗位之间使用持久化关系。证书来源于人社部考试计划，岗位关联属于系统按能力领域生成的“建议项”，不表述为强制任职资格。
- 图谱中的岗位、技能、工具、证书和等级节点都有真实关系边；匹配评分与学习路径直接复用这些关系，不再维护各自的硬编码清单。
- 国内职业名称、O*NET/ESCO 技能分类和中文岗位画像分层保存；所有跨库关系明确标记为 SkillBridge 本地映射，避免把派生结果冒充官方标准。

## 本地同步

管理员可在“数据源管理”页面点击“同步全部权威源”。同步后系统会校验下载文件、更新数据库和清除三端旧驾驶舱快照；用户未主动同步时，页面继续使用上次成功快照。
